            API 调用说明
        
        
    
    

        

            所有 API 返回统一 JSON 格式 {"code": 0, "message": "ok", "data": {...}}（/api/annotate 除外，返回纯文本）。
        


    
    

        

            GET/POST
            /api/annotate
            推荐
        

        

            快速标注：返回纯文本（非 JSON），命令行友好，支持管道。
        


        
📋 剪贴板一键标注：

        

            
            
pbpaste | curl -s -X POST http://127.0.0.1:5210/api/annotate --data-binary @- | pbcopy

        


        
🌐 GET 方式：

        

            
            
curl "http://127.0.0.1:5210/api/annotate?text=联系 13800138000"
# 返回：联系 13800138000 (4)

        

        
返回：纯文本（标注后的原文）；出错返回"错误：xxx"

    


    
    

        

            GET
            /api/phone_count
        

        
单号码查询，返回号码、归一化、重复数（JSON）

        

            
            
curl "http://127.0.0.1:5210/api/phone_count?phone=13800138000"

        

        
返回：{"code": 0, "data": {"phone": "...", "normalized": "...", "count": 3}}

    


    
    

        

            POST
            /api/phone_count_batch
        

        
批量查询号码重复数（最多 200 个）

        

            
            
curl -X POST "http://127.0.0.1:5210/api/phone_count_batch" \
  -H "Content-Type: application/json" \
  -d '{"phones": ["13800138000", "0571-88889999"]}'

        

        
返回：{"code": 0, "data": {"results": [{phone, normalized, count}, ...]}}

    


    
    

        

            POST
            /api/phone_count_text
        

        
从文本提取号码并标注，返回 JSON（含结构化数据）

        

            
            
curl -X POST "http://127.0.0.1:5210/api/phone_count_text" \
  -H "Content-Type: application/json" \
  -d '{"text": "联系张三 13800138000 或李四 0571-88889999"}'

        

        
返回：{"code": 0, "data": {"annotated_text": "...", "phones": [...], "phone_count": N}}

    


    
    

        
🐍 Python 调用示例

        

            
            
import requests

# 单号码查询
r = requests.get("http://127.0.0.1:5210/api/phone_count", params={"phone": "13800138000"})
print(r.json()["data"]["count"])

# 批量查询
r = requests.post("http://127.0.0.1:5210/api/phone_count_batch", json={"phones": ["13800138000", "0571-88889999"]})
for item in r.json()["data"]["results"]:
    print(f"{item['phone']} → 共 {item['count']} 家")
