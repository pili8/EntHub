AI 工具配置

主流 AI 工具（Claude Desktop / Cursor / VS Code 等）都使用相同的 mcpServers JSON 格式。复制对应配置 → 粘贴到配置文件 → 重启 AI 工具。

📦 stdio 模式：AI 工具自动启动 MCP Server，无需手动运行。适合单机使用，零运维。
选择 AI 工具：
📋 配置文件位置（不存在则创建）：
~/Library/Application Support/Claude/claude_desktop_config.json
📄 配置内容（复制到上面的文件）：
{
  "mcpServers": {
    "enthub": {
      "command": "{{ venv_python }}",
      "args": ["{{ mcp_script }}"]
    }
  }
}
⚡ Claude Code 用命令行一键添加：
claude mcp add enthub {{ venv_python }} {{ mcp_script }}
🌐 HTTP 模式：需要先点上方「启动」按钮，多端可共享访问。适合局域网或多设备使用。
📡 服务地址：
{{ server_url }}
📄 配置内容（所有 AI 工具通用）：
{
  "mcpServers": {
    "enthub": {
      "url": "{{ server_url }}"
    }
  }
}
