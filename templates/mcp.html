AI 工具配置

主流 AI 工具都使用相同的 mcpServers JSON 格式（MCP 协议标准）。复制配置 → 粘贴到对应文件 → 重启 AI 工具。

⚠️ 重要：两种模式不互通
📦 stdio 模式（AI 工具自动启动）
✅ Claude Desktop（仅支持此模式）
✅ Cursor、VS Code、Cline
✅ 绝大多数桌面 AI 工具
🌐 HTTP 模式（先启动再连接）
✅ Claude Code（CLI）
✅ Cherry Studio、ChatBox
⚠️ Claude Desktop 不支持
选择 AI 工具查看对应配置：
CC Switch 是 Claude Code / Codex / Gemini CLI 的配置管理工具，使用 GUI 表单配置 MCP，不用编辑 JSON 文件。
📋 在 CC Switch 中按以下表单填写：
服务器 ID enthub
名称 EntHub 企业信息
传输类型 stdio ✅
命令 * {{ venv_python }}
参数 * {{ mcp_script }}
应用绑定 勾选 Claude（自动同步到 ~/.claude.json）
💡 注意：CC Switch 不支持同步到 Claude Desktop，仅同步到 Claude Code / Codex / Gemini CLI 等 CLI 工具。
Claude Desktop：在「设置 → Developer → Edit Config」打开配置文件
📁 ~/Library/Application Support/Claude/claude_desktop_config.json
📄 方式一：复制以下 JSON 粘贴到配置文件的 mcpServers 中：
{
  "mcpServers": {
    "enthub": {
      "command": "{{ venv_python }}",
      "args": ["{{ mcp_script }}"]
    }
  }
}
📝 方式二：AI 工具提供表单时，按以下字段填写（每个字段均可单独复制）：
字段名 必填 填写值 操作
名称 / Name
服务器标识
 必填 enthub
传输类型 / Transport
协议类型
 必填 stdio
命令 / Command *
可执行程序路径
 必填 {{ venv_python }}
参数 / Args *
脚本路径
 必填 {{ mcp_script }}
⚡ Claude Code 用命令行一键添加（无需编辑 JSON）：
claude mcp add enthub {{ venv_python }} {{ mcp_script }}
